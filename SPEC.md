# Sunday Drive — cozy Three.js idle

Owner: Engineer (outer loop / Grok Build on Jarvis computer). Draft only — no commit/push/deploy without Andrew yes.

## Audience
Aging / returning gamers who like Melvor, Egg Inc., cozy idles, and offline progress. Low skill floor, high clarity, no FOMO timers.

## Fantasy
You own a quiet weekend car. Miles accrue while you are away. Golden-hour countryside rolls in Three.js. Spend miles on diner stops, mixtapes, tire upgrades, and thermos coffee. Prestige = pick a new destination and keep a permanent souvenir bonus.

## Trends to follow
- Offline earnings while closed (honest timestamp, no punish)
- Big readable numbers and one clear primary action
- Soft prestige / soft reset with permanent bonuses
- Satisfying automation unlocks (cruise control, autopilot playlist)
- Nostalgia without parody; calm color; no lootboxes

## MVP (playable local)
1. Vite + Three.js scene: road, horizon, simple car, day/dusk cycle
2. Click / space = drive for miles; also passive mi/s
3. Upgrades panel: tires, mixtape, diner, thermos (cost in miles, raise rate)
4. Offline catch-up modal on return
5. Prestige: new destination (reset upgrades, keep souvenir multiplier)
6. localStorage save
7. Large UI type, keyboard + click, mute toggle

## Out of scope for v1
Accounts, ads, microtransactions, mobile store, multiplayer

## Deliverable
Local URL (e.g. Vite on a free port), README how to run, path under /workspace/sunday-drive/. Bring Andrew the URL; do not deploy.
